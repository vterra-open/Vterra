# Translation Guide — Vterra & Valorys

Vterra welcomes translation of the framework documentation into any language.
Translation is one of the most valuable contributions a practitioner community
can make — it extends access to the organizations that need it most.

---

## What You Can Translate

- **FRAMEWORK.md** — the standalone Valorys framework specification
- **README.md** — the platform overview and framework summary

The book (*Take Control By Giving Up Control*) is licensed under
CC BY-ND 4.0, which does not permit derivative works. Translations of the
book require separate written permission from Vterra, Inc.

---

## How to Begin

1. Open a GitHub Discussion in the
   [Translations category](../../discussions) indicating:
   - The target language
   - Your background or organizational context (optional but helpful)
   - Whether you are working alone or with a team
2. We will acknowledge your effort within 72 hours and note it publicly
   so others working in the same language can find you

---

## Translation Standards

- Translations should be **faithful to the source** — not editorially adapted,
  summarized, or reinterpreted
- Preserve all headings, structure, and formatting as closely as the target
  language allows
- Where English terms have no direct equivalent, retain the English term and
  provide a parenthetical explanation on first use
- The following terms should remain in English in all translations, as they
  are registered trademarks:
  **Vterra, Valorys, Voxyn, GSO**

---

## Submitting a Completed Translation

- Name your file using the ISO 639-1 language code, e.g.:
  - `FRAMEWORK.es.md` (Spanish)
  - `FRAMEWORK.fr.md` (French)
  - `FRAMEWORK.pt.md` (Portuguese)
  - `README.es.md` (Spanish README)
- Submit as a pull request to the main branch
- Include a brief note identifying yourself as the translator and confirming
  the translation is faithful to the source

Accepted translations will be added to the repository and credited in the
README.
