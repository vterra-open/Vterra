Vercel
API bridge + web host
Hosts the session.js API file that connects HeyGen to ElevenLabs, and serves the agent web page to visitors. Code changes require a redeploy. Config changes in ElevenLabs or HeyGen do not.

Quick rule
Changing what the agent says or knows → ElevenLabs dashboard, live immediately.
Changing how the avatar looks or sounds → HeyGen dashboard, live immediately.
Changing the website pages or copy → Elementor / WordPress, live on save.
Changing code → GitHub commit → Vercel auto-redeploys.
